# NOVA — автономный AI-помощник для Android

Плавающий голосовой помощник, который работает **локально на устройстве**,
**не требует API-ключей и платных AI-сервисов**. Он Surface над другими
приложениями, слышит речь, читает экран через службу специальных возможностей,
выполняет многоэтапные задачи и помнит контекст диалога.

> Честность — часть продукта. Всё, что технически невозможно на Android,
> здесь не имитируется, а объясняется (см. раздел «Реальные ограничения»).

---

## Что реализовано по-настоящему

| Модуль | Что делает | Как |
|---|---|---|
| `core/CommandParser` + `IntentResolver` | понимает русские команды, сокращения, ошибки распознавания | локальный словарь фраз + нечёткое сопоставление (Левенштейн, транслитерация) |
| `core/FuzzyMatcher` | «тэлэглам» → Telegram, «инста» → Instagram, «ютюб» → YouTube | расстояние Левенштейна + фонетические поправки + транслитерация |
| `voice/VoiceEngine` | распознавание речи, синтез речи, прерывание, слово-будильник | системный `SpeechRecognizer` + `TextToSpeech`; опционально офлайн **Vosk** |
| `voice/VoskStt` | полностью офлайн-распознавание | Vosk, если модель установлена (инструкция ниже) |
| `service/NovaAccessibilityService` | видит экран, нажимает, вводит текст, делает скриншоты | Android Accessibility + `dispatchGesture` + `takeScreenshot` (API 30+) |
| `device/ScreenAnalyzer` | описывает экран, ищет кнопки, находит ошибки | реальное дерево интерфейса |
| `tasks/TaskPlanner` + `TaskAgent` + `TaskExecutor` | цель → план → выполнение → проверка | шаги с повторами, сменой стратегии и остановкой по «Стоп» |
| `notes/NotesManager` | заметки голосом, авто-название, поиск, категории, избранное | Room/SQLite, переживает перезапуск |
| `memory/MemoryRepository` | долгосрочная память, предпочтения, прогресс задач | Room/SQLite |
| `search/SearchEngine` | поиск без платного API | браузер + разбор открытой выдачи DuckDuckGo локально |
| `core/LocalAIEngine` | арифметика, дата/время, конвертация единиц, факты | полностью локально, без сети |
| `overlay/NovaCharacterView` | плавающий персонаж с 11 состояниями | рисуется кодом, анимации по состоянию |
| `camera/CameraAssistantActivity` | визуальный режим с фронтальной камерой | CameraX + `android.media.FaceDetector` |
| `service/AssistantCore` | связывает всё вместе | единого контура голос → команда → действие → ответ |

## Сборка и запуск

### 1. Требования
- Android Studio Hedgehog (2023.1.1) или новее, либо JDK 17 + Gradle 8.7+
- Android SDK 34, устройство/эмулятор с Android 9 (API 28)+

### 2. Собрать APK
```bash
# из корня репозитория
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
Или открыть папку в Android Studio и нажать **Run**.

### 3. Установить
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 4. Первый запуск (важно!)
NOVA ничего не делает без явных разрешений. В приложении нажмите по порядку:

1. **«Разрешить показ поверх других приложений»** — переключатель в системных настройках.
2. **«Микрофон, уведомления, камера, контакты»** — диалог разрешений Android.
3. **«Включить службу "NOVA — доступ к экрану»** — в настройках спец. возможностей.
   Именно она даёт помощнику видеть экран и нажимать кнопки.
4. **«Запустить помощника»** — появится плавающий персонаж.

После этого: «Нова, открой телеграм» или кнопка **🎤 Слушать команду**.

### 5. Офлайн-распознавание (по желанию)
Системный `SpeechRecognizer` работает на большинстве устройств, но зависит от
производителя. Для полного офлайна установите модель Vosk:
1. Скачайте `vosk-model-small-ru-0.22` с https://alphacephei.com/vosk/models
2. Распакуйте в `Android/data/com.nova.assistant/files/vosk-model/`
   (или `adb push model /sdcard/Android/data/com.nova.assistant/files/vosk-model`)
3. В настройках включите «Офлайн-распознавание (Vosk)».

Если модели нет, NOVA честно использует системное распознавание.

## Примеры команд

```
«Нова, открой тэлэглам»                     → Telegram
«открой ютуб»                              → YouTube
«зайди в инсту»                            → Instagram
«напиши в заметках привет»                 → заметка «привет»
«найди в гугле, почему греется телефон»    → поиск и краткий ответ
«посмотри, что на экране»                  → чтение экрана
«что мне делать?»                          → анализ ситуации
«запомни, что завтра купить зарядку»       → память
«открой телеграм, найди Сашу и напиши, что я скоро буду»
                                           → план из 5 шагов, отправка — после подтверждения
«разберись с заданием по истории»          → учебный план
«помоги пройти этот уровень»               → игровой помощник
«поставь таймер на 5 минут»                → реальный таймер
«стоп»                                     → немедленная остановка
```

## Архитектура

```
voice/VoiceEngine ──┐
                    ├──> service/AssistantCore ──> core/CommandParser + IntentResolver
overlay/Overlay     │             │               core/TaskPlanner
                    │             ├──> tasks/TaskAgent ──> tasks/TaskExecutor
                    │             │                       ├── device/AppLauncher
                    │             │                       ├── device/AccessibilityController
                    │             │                       ├── device/ScreenAnalyzer
                    │             │                       ├── notes/NotesManager
                    │             │                       └── search/SearchEngine
                    │             ├──> memory/MemoryRepository (Room)
                    │             └──> service/FloatingService (foreground)
service/NovaAccessibilityService ──┘
camera/CameraAssistantActivity ──> overlay/NovaCharacterView
```

`core/**` — чистый Kotlin без зависимостей от Android. Именно поэтому ядро
можно компилировать и тестировать на JVM (см. `tools/corecheck`).

## Проверка реально работающего ядра

Ядро команд, планировщик, безопасность, заметки, поиск и локальные знания
покрыты тестами, которые выполняются **по-настоящему** (не моки):

```bash
tools/corecheck/run.sh     # нужен kotlinc + JDK 17
# или вручную:
kotlinc app/src/main/java/com/nova/assistant/core/*.kt tools/corecheck/CoreCheck.kt -d /tmp/nova
java -cp /tmp/nova:$(kotlinc-home)/lib/kotlin-stdlib.jar corecheck.CoreCheck
```

На момент выпуска: **61 проверка, 0 ошибок**.

## Необходимые разрешения Android

| Разрешение | Зачем | Обратимость |
|---|---|---|
| `SYSTEM_ALERT_WINDOW` | плавающий персонаж поверх приложений | отключается в настройках |
| `RECORD_AUDIO` | распознавание речи | отзываеться в любой момент |
| `FOREGROUND_SERVICE(_MICROPHONE)` | постоянная работа помощника | кнопка «Выключить» |
| `POST_NOTIFICATIONS` | уведомление сервиса, таймеры | отзываеться |
| `CAMERA` | визуальный режим | только в этом режиме |
| `READ_CONTACTS` | «напиши Саше», «позвони маме» | отзываеться |
| `CALL_PHONE` | объявлено, но NOVA открывает набор номера (`ACTION_DIAL`) — звонок подтверждаете вы | — |
| `INTERNET` | только поиск в интернете | всё остальное работает без сети |
| Accessibility service | чтение экрана и нажатия | включается/выключается вами |

## Безопасность и контроль

- **Обязательное подтверждение** для: отправки сообщений, звонков, удаления
  заметок, изменения системных настроек.
- **Запрещено всегда**: оплата, переводы, покупки, смена паролей, удаление
  данных, сброс устройства.
- Кнопка **«Стоп»** в панели персонажа и в уведомлении останавливает и агента,
  и воспроизведение речи.
- Персонаж можно скрыть (длинное нажатие) — служба продолжает работать.
- Журнал действий — в «Истории задач»; память и заметки очищаются в настройках.

## Производительность

- Режимы **Экономичный / Стандартный / Интенсивный**.
- В экономичном — выключено постоянное слушание, каждая команда по нажатию.
- Нет бесконечных циклов:   limited число повторов шага (2), число прокруток (3).
- Скриншоты снимаются только по запросу (анализ экрана), а не постоянно.
- Камера работает только в визуальном режиме и сразу отключается при выходе.

## Реальные ограничения (честно)

1. **Распознавание речи** — системное, зависит от производителя устройства.
   На части устройств без Google-сервисов оно недоступно; тогда нужен Vosk.
2. **Автоматическое заполнение и отправка сообщений** в чужих приложениях возможно
   только через Accessibility. Если приложение блокирует доступ или использует
   `FLAG_SECURE`, NOVA сообщит об этом, а не сделает вид, что справилась.
3. **Игровой помощник** опирается на видимые элементы интерфейса. В играх без
   доступного дерева (OpenGL/Canvas без текста) он не видит игровое поле —
   и прямо говорит об этом. Для реального временного анализа нужен скриншот +
   модель компьютерного зрения (см. ниже).
4. **Локальная языковая модель** не поставляется в APK (это сотни МБ).
   Архитектура предусматривает подключение модели: интерфейс
   `core/LocalAIEngine` + точка расширения. Встроенный локальный обработчик
   считает, конвертирует, отвечает на факты и управляет командами — без сети.
5. **Интернет** нужен только для поиска в интернете. Всё остальное — офлайн.

## Структура проекта

```
app/src/main/java/com/nova/assistant/
  core/        чистая логика (Kotlin, тестируется на JVM)
  voice/       распознавание и синтез речи
  service/     фоновый сервис, служба спец. возможностей, ядро, таймеры
  device/      запуск приложений, доступ к экрану, анализ экрана
  overlay/     плавающий персонаж и панель
  tasks/       планировщик, агент, исполнитель, история
  notes/       заметки
  memory/      Room-база и репозиторий памяти
  search/      поиск без API
  camera/      визуальный режим и конвертация кадров
  education/   учебный помощник
  game/        игровой помощник
  permission/  разрешения
  settings/    настройки
  ui/          списки и адаптеры
tools/corecheck/  проверка ядра на JVM
```

Устаревший прототип лежит в `legacy/` (там использовался платный API-ключ —
поэтому он не является основой NOVA).
